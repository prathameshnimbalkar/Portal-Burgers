# 🍔 Burger Hub • Alpha Portal

A lightweight, high-performance React application built with Vite and pure Vanilla CSS.

## Features

- **🏠 Welcome Page**:
  - Hero introduction with quick actions.
  - "Today's Special" burger showcase.
  - Live statistics and overview cards.

- **👥 Users Directory**:
  - Mock API integration simulating network delay (`fetchUsersApi`).
  - Search by name, email, or favorite burger.
  - Filter by team & member roles.
  - User detail modal with contact info and favorite burgers.
  - Add Member form with mock POST mutation.
  - Real-time error handling with retry mechanism (testable via "⚠️ Test Error" button).

- **⚡ Zero Heavy Bloat**:
  - Built with standard React 19 + Vite.
  - Crafted with pure Vanilla CSS, custom CSS tokens, dark mode palette, and micro-animations.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
